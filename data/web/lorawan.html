⚙️ Configuração LoRaWAN

Habilitar LoRaWAN
Ativar ou desativar comunicação LoRaWAN
OTAA é mais seguro e recomendado para produção
Classe A é ideal para dispositivos battery-powered

🔐 Parâmetros OTAA

Identificador único do dispositivo (16 caracteres hex)
Identificador da aplicação (16 caracteres hex)
Chave raiz AES-128 (32 caracteres hex) - NUNCA compartilhe!

🔑 Parâmetros ABP

Endereço de rede (8 caracteres hex)
Chave de sessão de rede AES-128 (32 caracteres hex)
Chave de sessão da aplicação AES-128 (32 caracteres hex)

🔧 Configurações Avançadas

ADR (Adaptive Data Rate)
Permite que o servidor otimize a taxa de dados automaticamente
Uplinks Confirmados
Solicita confirmação do servidor para cada mensagem (consome mais energia)
Ignorado se ADR estiver habilitado
Potência de transmissão (2-20 dBm, padrão: 14)
Intervalo entre transmissões (30-86400 segundos)

📌 Configuração de Pinos SX1276

ℹ️ Informações LoRaWAN

LoRaWAN é um protocolo de rede de longa distância e baixo consumo para IoT.

  • OTAA: Dispositivo negocia chaves com servidor (mais seguro)
  • ABP: Chaves pré-configuradas no dispositivo (menos seguro)
  • DevEUI: Identificador único global do dispositivo
  • AppKey: Chave raiz para derivar chaves de sessão (OTAA)
  • Classe A: Menor consumo, recebe apenas após transmitir
  • ChirpStack: Servidor de rede compatível com este dispositivo
