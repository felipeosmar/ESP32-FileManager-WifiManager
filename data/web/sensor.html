ℹ️ Informações

Sobre o Sensor SHT20:

  • Sensor digital I2C de temperatura e umidade
  • Endereço I2C: 0x40 (fixo)
  • Faixa de temperatura: -40°C a +125°C
  • Faixa de umidade: 0% a 100% RH
  • Precisão: ±0.3°C para temperatura, ±2% RH para umidade
  • Resolução: 14 bits para temperatura, 12 bits para umidade

Conexão I2C:

  • Usa os mesmos pinos I2C do display OLED
  • Conecte VCC ao 3.3V do ESP32
  • Conecte GND ao GND do ESP32
  • Conecte SDA ao mesmo pino do display (configurado em Display OLED)
  • Conecte SCL ao mesmo pino do display (configurado em Display OLED)

Recursos:

  • Leituras automáticas em intervalo configurável
  • Verificação CRC para integridade dos dados
  • Suporte para Celsius e Fahrenheit
  • Soft reset do sensor em caso de falha
